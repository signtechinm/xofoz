# XOFOZ Products Hub Implementation Plan

## Phase 1 — Content foundation

- Convert the 19 wireframe categories into typed, maintainable product data.
- Record brands, highlighted authorisation status, and valid existing destination routes.
- Keep authorisation claims easy to review before publishing.

## Phase 2 — Products hub page

- Create `/products` with page metadata, canonical URL, breadcrumbs, and structured data.
- Implement the hero, proof metrics, authorised-supply message, portfolio grid, trust content, partnerships, and quote section.
- Use semantic headings, accessible links, and descriptive labels.

## Phase 3 — Conversion and site integration

- Add a WhatsApp-powered product quote form.
- Update the global Products navigation item to point to `/products`.
- Add `/products` to the XML sitemap.

## Phase 4 — Responsive visual system

- Match the current XOFOZ dark visual language while translating the wireframe into production UI.
- Use three product columns on desktop, two on tablet, and one on mobile.
- Add focus, hover, reduced-motion, and small-screen states.

## Phase 5 — Verification

- Run TypeScript and production build checks.
- Inspect the rendered desktop and mobile page.
- Correct layout, route, accessibility, and runtime issues found during QA.
